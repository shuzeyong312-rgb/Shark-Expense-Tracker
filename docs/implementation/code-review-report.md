## 问题清单

### P0

未发现有足够证据确认的问题。

### P1

1. **设备配置变化使当前页面和未保存草稿消失**。位置：`app/src/main/java/com/example/personalledger/LedgerApp.kt:60`、`:61`、`:72`，`RecordScreens.kt:35`。导航栈和编辑目标只使用 `remember`，Activity 因旋转、字体大小或其他配置变化重建时重新回到 home；记录面板即使使用 `rememberSaveable`，页面也不再位于导航栈，草稿不能继续。复现：新增账单，选分类并输入金额和备注但不保存，旋转设备；页面回到明细，输入内容丢失。已保存的数据库记录不会因此被删除。建议保存导航及编辑目标，并补充重建场景测试。

### P2

2. **保存的图表周期随时间推移会落在周期选择栏之外**。位置：`app/src/main/java/com/example/personalledger/ChartScreens.kt:34`–`:38`、`:53`–`:56`；`LedgerViewModel.kt:49`–`:52`。所选日期永久保留，但周选项始终按当前日期重新生成最近六个完整周。复现：选择六周入口中最早的一周，离开应用，下一周再打开图表；统计仍指向旧周，但选择栏不包含该周，也没有选中项，无法通过栏返回该周期。月/年锚点发生类似窗口移动时也可能出现。建议对保存的选择与有效入口统一处理，并明确保留选择和可见范围的关系。

3. **图表最高值没有名称，无法判断右侧数字的含义**。位置：`ChartScreens.kt:60`–`:62`。右侧仅输出数值，无“最高单日”或年视图的“最高单月”标签；模拟器空图表实测右侧仅显示 `0.00`。复现：打开图表或分类详情，在周/月/年之间切换观察汇总区。Spec 3.4/3.5 要求展示最高值及相应口径；应随周期显示可辨认的标签。

4. **导航选中图标未切换状态，部分图标用字符替代原型素材**。位置：`LedgerApp.kt:87`–`:94`；`OtherScreens.kt:54`–`:57`、`:79`。所有导航项均调用同一 `CatIcon(..., false)`，仅文字加粗；“我的”菜单及账伴建议卡使用 Unicode 字符代替原型内嵌图形。复现：切换底部导航，或打开我的/账伴页面对照原型和图标映射。映射表要求保留选中状态及原型图标视觉语言。应按原型使用相应本地图形并核对状态。

5. **趋势图点选采用向下取整，实际点击位置与被选数据点不一致**。位置：`ChartScreens.kt:100`–`:101`。绘图点位按 `i/(n-1)` 均匀分布，但点击索引直接截断；例如七点图在第二点与第三点正中偏向第三点的位置点击，仍选中第二点。复现：在周趋势图两个相邻点之间靠近右侧点处点击，观察高亮/日期。应选择距离点击位置最近的点，并覆盖边界测试。

6. **大数据量分类和备注详情会一次组合全部账单行**。位置：`ChartScreens.kt:59`、`:90`、`:145`、`:161`。页面使用可滚动 `Column` 逐条构建全部记录；10,000 笔测试只验证查询和计算，未验证这些页面的渲染。复现条件：同一分类或备注在所选年度有大量账单，进入详情并滚动；存在明显卡顿或内存压力的风险，当前没有测量数据，不能断言具体阈值。建议以大样本实测并按需使用惰性列表。

### P3

7. **记账面板取消操作的语义不一致**。位置：`RecordScreens.kt:70`、`:74`。新增时“取消”仅收起面板，保留草稿；编辑时直接退出编辑。复现：新增时输入金额后点击面板右上“取消”，重新选择分类，金额仍在。规格明确点分类信息收起保留草稿，取消新增不保存；当前行为不会写入数据，但“取消”与仅收起的区别不清，需按冻结原型确认文案和行为。
